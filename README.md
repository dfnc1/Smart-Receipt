# 🧾 SmartReceipt

Aplikasi mobile untuk mencatat dan mengelola struk belanja, dibangun dengan **Flutter**.

---

## 🚀 Menjalankan Proyek

```bash
flutter pub get
flutter run
```

## 📦 Tech Stack

- **Flutter** + Dart
- `shared_preferences` — penyimpanan data lokal

## 📋 Requirement

- Flutter SDK ≥ 3.13.5
- Android Emulator / perangkat fisik
